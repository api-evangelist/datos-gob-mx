# datos.gob.mx - Sitio oficial de datos abiertos del Gobierno de la República (datos-gob-mx)

datos.gob.mx - Sitio oficial de datos abiertos del Gobierno de la República is a open data portal open-data portal for Mexico running **CKAN**, exposing a standardized catalog API over ~1,652 datasets.
